# 外部参考和市场观察

## 已观察到的趋势

- Linear 已经支持把 issue 分配给 GitHub Copilot coding agent，并将进度回写到 activity timeline。
- GitHub Copilot cloud agent 支持在隔离环境中研究 repo、制定计划、改代码、运行测试并创建 PR。
- VS Code / GitHub 正在强化 agent session、实时进度、PR card、session log 和 follow-up instruction。
- 这些产品证明“issue -> agent -> PR -> review”正在成为主流，但它们仍偏通用软件流程。

## VibeBoard 的机会

- 更专注 vibe coding 中从 idea 到验收的追踪闭环。
- 把 preview 作为任务卡片的一等公民。
- 用视觉差异和可执行验收减少 PM / Dev 翻译成本。
- 把 Agent 过程变成可观测 timeline，而不是黑盒后台任务。

## 竞品维度

| 产品 | 强项 | VibeBoard 可差异化点 |
| --- | --- | --- |
| Jira | 企业流程、复杂权限 | 太重，非运行时驱动 |
| Linear | 速度快，AI agent 集成 | 通用 issue 工具，vibe coding 执行证据不是核心 |
| GitHub Copilot agent | 强代码执行和 PR 流程 | 缺少产品级看板和 PM 视觉验收体验 |
| Cursor / Windsurf | IDE 内 AI 编程体验 | 更偏个人/代码编辑，不是团队进度层 |
| Storybook / Chromatic | 组件视觉审查 | 不负责敏捷任务和 agent 执行 |

## 建议切入点

从“vibe coding 任务 Review 很难”切入，而不是从“我要替代 Jira”切入。
